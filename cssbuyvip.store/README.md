# CSSBuyVIP Store

Complete static deployment package for cssbuyvip.store.

## Deploy to GitHub Pages

Upload every file and folder in this directory to the repository root, then enable Pages from the main branch.

## Deploy to Cloudflare Pages

Connect the repository, leave the build command empty, and set the output directory to the repository root.

## Included

- Homepage with embedded CSSBuy + VIP logo and favicon
- Ten-category and ten-product mobile two-column layouts
- Buyer guide library
- Three crawlable article pages
- robots.txt, sitemap.xml, _headers and 404.html
