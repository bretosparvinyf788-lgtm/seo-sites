CLOUDFLARE PAGES DIRECT UPLOAD

1. Extract the ZIP file.
2. Open the extracted folder.
3. Upload ALL files inside it so index.html, sitemap.xml and robots.txt are at the deployment root.
4. Do not upload the outer extracted folder as an extra nested directory.
5. After deployment succeeds, verify:
   https://usfansvip.store/
   https://usfansvip.store/sitemap.xml
   https://usfansvip.store/guides/

This package is static and requires no npm install or build command.
