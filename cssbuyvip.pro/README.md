# CSSBuyVIP Pro

GitHub Pages-ready static site for **cssbuyvip.pro**.

## Publish

Upload the contents of this folder to the repository root, commit them to the branch used by GitHub Pages, then choose **Deploy from a branch** with the **/(root)** folder.

The package includes the homepage, the buyer-guide index, three independent long-form article pages, local brand assets, favicon, robots.txt, sitemap.xml, CNAME and .nojekyll.
