SUPERBUY RETURNS AND EXCHANGES BEFORE INTERNATIONAL SHIPPING.

A deadline-first system for turning warehouse evidence into a clear keep, return or exchange decision while domestic options still exist.

SuperbuyVIP EditorialPublished September 8, 2026Independent guideApprox. 1,660 words

A return is not the opposite of a purchase. It is a second transaction with its own eligibility rules, evidence, domestic shipping cost and deadline. When an item bought through Superbuy reaches the warehouse, the useful question is not simply whether you like it. The useful question is whether the received item conflicts with a promise the seller made and whether a practical domestic remedy still exists.

This distinction matters because international shipment changes the problem. Before export, the item is in China and Superbuy's shopping agent can communicate with the domestic seller. After export, the buyer has a cross-border parcel, higher transport costs and a much weaker path back to the original merchant. The warehouse stage is therefore a decision window. Treat it as one, and a visible defect can become an organized case rather than an unpleasant discovery at home.

Read the exit terms before you place the order

Start on the live product page. Record the seller, selected variation, stated dispatch time, return or exchange marks, exclusions and who pays domestic return freight. Do not assume that a familiar marketplace logo creates a universal return right. The relevant promise belongs to the specific listing and seller policy available when the order is placed.

Translate that policy into a short exit note. It might say: return permitted for an undisclosed defect; buyer pays freight for preference-based returns; customized color cannot be returned; packaging and labels must remain intact. Save screenshots with the capture date because listings and shop terms can change. If a condition is unclear, ask through the order enquiry before payment. Superbuy's published shopping workflow says buyers can use order enquiry to contact the purchasing agent, who can communicate with the seller.

The cheapest time to discover that a product is non-returnable is before payment. A warehouse photo cannot create a seller obligation that was absent from the listing.

Classify the source instead of applying one rule to every order

A mainstream retail order, a 1688 wholesale order and a secondhand purchase do not carry the same after-sales assumptions. Superbuy's current 1688 guidance tells buyers to prefer listings carrying guarantee or time-based exchange marks, including 7-, 15-, 21- and 60-day marks. It also states that the result of a return or exchange negotiation follows the seller's policy and that the user bears return shipping costs in the described limited after-sales service.

The same 1688 guidance separates marked products from unmarked Type B products. For marked products, it describes a 5% sampling inspection for a single SKU, capped at 20 units and with a minimum sample of five. It warns that sealed original packaging may not be opened to count contents. Unmarked Type B products are described as having no sampling inspection, no standard photo service and no after-sales service. Those limits should shape the buying brief before a bulk order, not surprise the buyer after arrival.

Secondhand orders require another boundary. Superbuy's current secondhand notice says used-item sellers do not provide return or exchange service. Paying the platform's secondhand purchasing fee does not convert a one-off resale listing into a retail return program. For such items, the safest return strategy is prevention: seller questions, preserved listing evidence and targeted inspection before accepting the risk.

Write acceptance rules that a warehouse image can test

“I do not like it” is difficult to evaluate remotely. “The ordered navy size L arrived as black size M” is testable. Before the parcel reaches the warehouse, list three to six conditions that would justify action. Use observable facts: label size, model number, measured length, item count, included accessory, visible crack, color family or printed design.

Separate a seller mismatch from a preference change. A mismatch means the received item differs from the paid variation or an explicit seller statement. A preference change means the item may be correct, but the buyer no longer wants it. That classification can affect eligibility and who bears domestic freight. Do not exaggerate a preference change into a defect. A factual case is easier for the agent and seller to review.

For bundles or wholesale quantities, define the counting unit. “Ten packs” is ambiguous when each pack should contain twelve pieces. Record expected cartons, packs and individual units. Remember that Superbuy's 1688 notice limits what the warehouse checks when goods remain in original sealed packaging. If exact quantity is commercially critical, clarify what inspection is possible before ordering.

Inspect while the item is still reversible

Superbuy's shopping guide says warehouse staff carry out quality inspection, take photos and contact the buyer when problems are found. Standard inspection is a useful first screen, not proof of every hidden attribute. Open the warehouse record as soon as it appears and compare it with the exact paid variation and your acceptance rules.

If the standard images do not answer the decisive question, request only the evidence that will. Superbuy's current fee table lists a detailed photo at CN¥2 per piece, re-inspection at CN¥6 per order and detailed inspection at CN¥5.50 per item. Re-inspection covers specified attributes such as style, quantity, color, size, model, damage and obvious defects and includes three inspection photographs. Detailed inspection extends to areas such as linings, zippers, pockets, smaller stains, discoloration, scratches and snags.

The service name is less important than the question. For shoes, ask for both size labels and the defect area. For a bag, request the interior, closure and included strap. For a device, ask for the model label rather than a decorative exterior angle. One decisive photograph is more useful than five generic photographs that do not resolve eligibility.

Build a discrepancy packet, not a long complaint

A domestic after-sales request should be easy to audit. Put the order number first. Then state the ordered variation, the seller's promise, the warehouse observation and the remedy requested. Attach a small numbered evidence set: listing screenshot, paid selection, seller message if relevant, full warehouse photo and close view of the discrepancy.

Use neutral language. “Listing specifies 42; warehouse label shows 41” is stronger than “seller sent garbage.” If the lighting makes color uncertain, say that and request a daylight or label photo. If a hidden part was not inspected, do not claim it is missing until the package has been checked appropriately. Precision preserves credibility and reduces the number of clarification rounds while a seller-side clock may be running.

Choose one primary outcome: return for refund, exchange for the correct variation, partial refund while keeping the item, or additional evidence before deciding. An exchange may look attractive but can add two domestic journeys and more waiting. A refund may exclude original domestic shipping or require return freight. A partial refund avoids a second shipment but only makes sense if the item remains useful.

Calculate the remedy before authorizing it

Compare the recoverable amount with the cost of action. Include domestic return freight, any nonrefundable service or payment costs, replacement domestic freight, inspection spending and the value of delay. Do not count the original item price as fully recoverable until the seller has agreed to the remedy and its conditions.

For a low-value item, paying return freight and waiting for a replacement may cost more than keeping, donating or disposing of it. For an expensive wrong model, the same freight can be a small price for preventing a much larger loss. The decision should follow numbers and usefulness, not the desire to “win” a dispute.

Keep refund destinations separate in your record. A seller refund, Superbuy account balance adjustment, payment-method reversal and shipping compensation are not interchangeable events. Note the expected amount, responsible party, status and date. Close the case only when the actual credit can be matched to the order.

Protect eligibility until the case is finished

Do not request irreversible warehouse services before deciding to keep the product. Preserve tags, labels, accessories, retail packaging and seals unless inspection requires an agreed exception. Superbuy's value-added service table specifically warns that brand-tag removal may make goods ineligible for return or exchange. That is a practical reminder that lower shipping weight should not be optimized before product acceptance.

Do not combine a disputed item into an international parcel. Do not ask for packaging removal, customization, cleaning or alteration while a return is being considered. Record every instruction and response in the order timeline. If the seller approves a return, confirm the address, carrier requirement, deadline, included parts and evidence of domestic delivery before the warehouse sends it.

Run one clock for eligibility and another for operations

The warehouse storage period is not the return period. Superbuy publishes a 90-day free storage allowance for standard stocked items, but a seller's after-sales window can be much shorter and listing-specific. Record warehouse arrival, first review, extra-evidence request, agent contact, seller response and approved return deadline as separate dates.

Set your internal decision date earlier than the seller deadline. The agent needs time to read the request, communicate, receive an answer and arrange domestic shipment. Weekends, seller delays and incomplete evidence consume that margin. Checking the order every few days without a deadline is not a system; it is a way to discover that an otherwise valid option expired.

Use a final release gate before international shipping

Every warehouse item should end in one recorded state: accepted, return in progress, exchange in progress, refund pending or abandoned. Only accepted items should be available for parcel submission. Confirm that their visible condition, variation, quantity and essential accessories have passed the written rules, then move to route, packaging and freight decisions.

A good Superbuy return workflow is deliberately short. Capture the seller's exit terms before payment, inspect against observable rules, request decisive evidence, calculate the remedy and protect the item's condition until the case closes. The agent can purchase, inspect and communicate, but the buyer still has to define the mismatch and act while the domestic path remains open. That discipline turns “something looks wrong” into a dated decision with evidence, cost and a clear next action.
